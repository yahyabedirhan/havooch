Pause the video. Point at the frame. Send the cat.

Havooch is a native macOS video player for giving feedback to coding agents. You pause on a moment, draw a region, and write what you mean. ⌘↩ sends every note to the agent you already have running, with the time, the keyframe, the crop and the transcript around it. The answer comes back to the frame.

Install for Mac Source on GitHub

Free and open source under MIT. Needs macOS 26. Listens for Claude Code, Codex, Gemini CLI and any agent with a shell.

What happens in there

  1. You pause, and point

    Space pauses on the moment. Drag on the frame to mark a region. Write one line, or ten. ↩ queues the note and you keep watching. Every moment you write on becomes a thread with its own pin on the timeline.

  2. One ⌘↩ sends the queue

    All the notes go together, grouped by thread. For each one the agent gets the exact time, the keyframe, the region crop, the transcript fifteen seconds either side, and the context you gave the video. Enough to act without asking you to describe what you were looking at.

  3. The agent works in your repo

    On its side it is one skill, havooch-mate. The agent acknowledges the send, does each message's work, commits once per message, and when something is unclear it asks on the thread instead of guessing. Your answer goes straight back.

  4. The answer lands on the frame

    One to three plain sentences and the commit, in the thread beside the frame. The thread list sorts the review by who acts next: Needs you, With agent, Queued, Done.

The unglamorous facts

  • A real Mac app: AppKit and SwiftUI, the system toolbar, native surfaces in Default Light and Dark. Tokyo Night, Dracula, One Dark Pro, Catppuccin and GitHub ship too.
  • Agents can drive the player under a lease: open a video, seek, comment, take a screenshot. You take the controls back from the toolbar at any time.
  • Reviews are keyed by the video's content, so a renamed or moved copy opens the same threads.
  • No account, no server. The wire between the player and the agent is a local socket and a command line.

Install

Either line installs the app, the havooch command and the havooch-mate skill.

Homebrew brew install --cask yahyabedirhan/tap/havooch
Script curl -fsSL https://raw.githubusercontent.com/yahyabedirhan/havooch/main/scripts/install.sh | bash

The script checks the release's SHA-256 before it installs; --uninstall removes everything. Havooch is signed but not notarized, so macOS asks once on first launch: System Settings, Privacy & Security, Open Anyway. Then open the demo from the empty window and tell your agent to listen for Havooch feedback.

The cat in the world

I named it after my cat, Havuç. He is orange and white, and havuç is Turkish for carrot. Havooch is how you say it, hah-VOOCH, so that you and I type the same thing. The logo is his face, drawn from a photo and made a little cuter; the sprite in the scene is the same face with fewer pixels.

I built Havooch because I kept describing a frame to an agent in words when I could have pointed at it. Havuç has no opinion on this, but he does sit in front of the screen.

Pause the video.
Point at the frame.
Your coding agent fixes it there.

Havooch is a native macOS video player for giving feedback to coding agents. You pause, draw a region if you need to, and write what you mean. One ⌘↩ sends every note to the agent you already have running, with the exact time, the keyframe, the region and the transcript around it. The agent does the work in your repo and answers beside the frame.

Install for Mac Read the source

Free and open source under MIT. Needs macOS 26. Works with Claude Code, Codex, Gemini CLI and other agents that can run a shell.

One loop, five moves.

You watch and write. The agent reads, works and answers. Nothing leaves the frame it is about.

  1. 1

    Pause

    Space pauses on the moment. The playhead time becomes the thread's time.

  2. 2

    Point

    Drag on the frame to mark a region. The crop travels with your note.

  3. 3

    Comment

    Write one line or ten. ↩ queues it. Keep watching, keep queueing.

  4. 4

    Send

    ⌘↩ sends the whole queue as one batch, grouped by thread.

  5. 5

    The agent answers

    It commits in your repo and replies on the thread, beside the frame. If something is unclear, it asks there first.

What the agent gets

For each thread in a send: the exact time, the keyframe image, the region you drew and its crop, the transcript fifteen seconds either side, and the context you gave the video. Enough to act without asking you to describe what you were looking at.

On the agent's side it is one skill, havooch-mate. Tell your agent to listen for Havooch feedback, and the player shows it as listening.

{
  "number": 1, "time": 3.017,
  "keyframePath": "…/t-1.png",
  "transcript": [{ "text": "Pause and point…" }],
  "messages": [{
    "text": "The intro goes by too fast.",
    "region": { "x": 0.22, "y": 0.42, "w": 0.18, "h": 0.15 },
    "cropPath": "…/m-9.png"
  }]
}

A Mac app, through and through.

AppKit and SwiftUI, the system toolbar, one surface colour across the window and hairlines where other apps paint bands.

Threads, sorted by who acts next

The list groups your review into Needs you, With agent, Queued and Done. Each row keeps its keyframe, its state and who spoke last, so you can read the state of a review in a glance and go straight to the thread that is waiting on you.

When the agent is unsure, it asks on the frame

A question gets its own card and moves the thread to Needs you. Your answer skips the queue and goes straight back, so the agent never guesses at the thing you can settle in four words.

A real conversation

Your messages on the right, the agent's on the left with its own logo. Each message carries its state: queued, sent, acknowledged, working, done or failed.

Your editor's colours, if you like

Default Light and Dark use the native surfaces. Tokyo Night, Dracula, One Dark Pro, Catppuccin and GitHub ship built in, and a theme file of your own can extend any of them.

Agents can drive the player too.
A leased command line lets an agent open a video, seek, comment and take a screenshot. You take control back any time.
Reviews stay with the video.
Threads are keyed by the file's content, so a renamed or moved copy opens the same review.
Context travels.
A sidecar file or a note in the app tells the agent what the video is about and which repos it touches.

Install in one line.

Both ways install the same release build, the havooch command and the mate skill.

Homebrew

brew install --cask yahyabedirhan/tap/havooch

Updates with brew upgrade.

Install script

curl -fsSL https://raw.githubusercontent.com/yahyabedirhan/havooch/main/scripts/install.sh | bash

Checks the release's SHA-256 before it installs. --uninstall removes it all.

First launch. Havooch is signed but not notarized, so macOS asks once. Open System Settings, Privacy & Security, and choose Open Anyway. Then try the demo from the empty window.

About the name

I named it after my cat, Havuç. He is orange and white, and havuç is Turkish for carrot, which is the whole story. I spell it the way it sounds, hah-VOOCH, so that you and I type it the same way. The logo is his face, drawn from a photo and made a little cuter.

I built Havooch because I kept describing a frame to an agent in words when I could have just pointed at it. If you review screen recordings, demos or renders with an agent in the loop, I hope it saves you the same breath.

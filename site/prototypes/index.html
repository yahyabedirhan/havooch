Havooch landing page prototypes

Storybook is the chosen direction for the public page: one three-page site with the pixel-world story at /, the app at /studio and the command line at /cli, all in one look and feel. Below it are the three references it was built from. They are self-contained static pages beside the current landing page. Each folder has a README with the design plan, and a preview/ folder with the screenshots shown here. Open a prototype and resize the window; switch your system appearance to see light and dark.

  • storybook chosen

    Ink on paper, a picture book: ivory paper and ink-blue type in Young Serif and Source Serif 4, the diorama as a tipped-in colour plate, scenes as alternating book spreads, a Contents list in the margin.

    • / the pixel-world story
    • /studio the app, with screenshots
    • /cli the command line
    Open the prototype

  • pixel-world reference

    The starting point of storybook's home page. A lit isometric pixel diorama of the loop, rendered in software from code: the screening room where Havuç pauses and points, the path the notes travel, and the agent's workshop where the replies come from. Dark first, with a dusk light mode.

    Open the prototype

  • studio reference

    The source of storybook's /studio page. A calm product page in the native-Mac tradition: real screenshots, an annotated hero window with callouts, and the loop explained in five moves. One typeface, one accent, a lot of air.

    Open the prototype

  • wire reference

    The source of storybook's /cli page. The developer-tool direction, centred on the agent's side of the loop: a terminal that plays one send, both ends of the wire laid side by side, the JSON the agent reads and the command line. Blueprint paper with a faint grid.

Havooch landing page prototypes

Three directions for the public page, each a self-contained static page beside the current landing page. Each folder has a README with the design plan, and a preview/ folder with the desktop and phone screenshots shown here. Open a prototype and resize the window; switch your system appearance to see light and dark.

  • pixel-world

    A lit isometric pixel diorama of the loop, rendered in software from code: the screening room where Havuç pauses and points, the path the notes travel, and the agent's workshop where the replies come from. Dark first, with a dusk light mode.

    Open the prototype

  • studio

    A calm product page in the native-Mac tradition: real screenshots, an annotated hero window with callouts, and the loop explained in five moves. One typeface, one accent, a lot of air.

    Open the prototype

  • wire

    The developer-tool direction, centred on the agent's side of the loop: a terminal that plays one send, both ends of the wire laid side by side, the JSON the agent reads and the command line. Blueprint paper with a faint grid.

    Open the prototype
Screenshots were taken with headless Chromium at 1440 and 390 px wide; the previews here are the first screen of each page.

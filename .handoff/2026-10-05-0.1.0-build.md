# Handoff: build Video Review 0.1.0

Build the effort `effort:0.1.0` on the branch `0.1.0` in this worktree, and deliver one pull request to `main`. The prototype round is done. 0.1.0 combines proto-2's code with proto-1's design details, a few UX parts from proto-3, and the maintainer's feedback.

## Read first

- Spec: `Spec: Video Review 0.1.0` (#20). Tickets: every issue labelled `effort:0.1.0` (#21 to #34), with native blocking links. Start with `Chore: Write the 0.1.0 low-level design, the glossary and the ADR correction` (#21).
- `docs/prototypes/`: the maintainer's feedback, verbatim, and every numbered decision. The spec cites them as (D x.y).
- `AGENTS.md` and `docs/adr/0001-agents-control-the-app-through-a-leased-cli.md`.
- The prototype branches: `proto-2` is the base, `proto-1` gives the details of decisions A.4 to A.8, `proto-3` gives the footer and the background-colour segmentation. Their worktrees are `~/.treehouse/video-review-14a6ef/{1,2,3}/video-review`; read them, don't edit them. Each has its own `docs/low-level-design.md`.

## How to run

- Use the `orchestrate-effort` skill. Delegate each ticket; integrate on `0.1.0`.
- Work fully autonomously. The maintainer will not answer questions in the middle. Choose the simplest option that fits the spec and the decisions, and record it.
- Use the `session-status` tool from the start: report each ticket (`started`, `landed`, `stopped`, effort `0.1.0`), record review-later decisions and surprises, and post the end list at the end.
- Use the `apple-design` and `write-swift` skills for every UI and Swift ticket.
- The issues are yours to update: tick acceptance criteria, comment evidence, close each ticket when it lands.
- `QA: Check the 0.1.0 interactions by hand` (#34) is for the maintainer. Leave it open.

## The Mac

- The installed prototypes are `/Applications/Video Review (proto-N).app`. 0.1.0 installs as `/Applications/Video Review.app`, so it never replaces them.
- Take the app-control lease before `make install` and release it at the end, as AGENTS.md says. Other agents may use the prototype apps; never take their lease over.
- When a permission prompt blocks you (Screen Recording, Speech Recognition), ping the maintainer with `shipyard ping "<what to grant>" --body "<where and why>" --from video-review-0.1.0 --herdr` and work on another ticket meanwhile.

## Delivery

Open the pull request with `to-pr` from `Chore: Run the 0.1.0 acceptance scenario and open the pull request` (#33): the decision log, the acceptance output, the screenshots and what needs a check by hand. Ask the maintainer before you merge. Don't run `settle-effort`.
